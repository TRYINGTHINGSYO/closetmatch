# Mirror Check

## Purpose

Private full-body outfit review focused on clothing coordination — not attractiveness or body judgment.

## User flow

Consent → permission → capture/upload → quality note → analyze → feedback → agree/disagree → replace/retake/delete/wear.

## Safety rules

Forbidden: body criticism, attractiveness scores, medical/sexual/personality inference, definitive social predictions.

Server and client both reject unsafe language patterns.

## Result structure

Overall / color / style / proportion / occasion / weather scores, positive observations, suggested changes, suggested roles to replace, confidence, image quality, user agreement, retention status.

## Retention

Policies: delete after analysis (default), save original, analysis only, reduced, blurred preview. Photos private; signed URLs; deleted on request; excluded from analytics.

## Learning integration

Mirror Check influences recommendations only when the user agrees/disagrees or wears the outfit afterward. The user’s final opinion outweighs the AI.
