# Roadmap

## MVP (this repo)

Vertical slice: auth → closet → outfits → wear → recommendations → Mirror Check, plus migrations, RLS, tests, docs.

## Beta

Live Supabase Auth (magic link, Google, Apple), live vision provider, notification scheduling, stronger offline sync, polished tablet layouts.

## Version 1

Richer analytics, natural-language search conversion, smarter style insights UI, closet locations nesting UX, cost-per-wear suggestions (non-pressuring).

## Later

- Virtual try-on (simulation-labeled)
- Social / stylist / parent-managed profiles
- Shopping suggestions & packing lists
- Travel planning, resale support, tailoring reminders
- Smart closet hardware integrations
